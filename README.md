말을 물가에 데려다 놓을 수는 있어도 물을 마시게 할 수는 없다. 공부를 하게 만드는 방법은 없다. 스스로 공부를 해야지. 스스로 공부를 하자고 마음먹거나 그러한 계기를 갖는 것이 무엇보다 중요하다. 학습중인 학습자들은 어떤 목적을 가지고 있나? 어떤 과정을 수강 중일 때, 취득 점수와 무관하게 오직 해당 과정 완주만이 목표인 경우가 과연 많을까?

장학금을 받는 학습자가 더 학습에 대한 의지가 클까? 부자 동네에 산다면(상대적으로 부유한 상황이라면) 안일함에 학습에 다소 나태해질까? 더 많은 압박에 학습을 강도높게 할까? (외부요인일 뿐 자신의 의지는 그 개인이 아닌 이상 알 수 없다 사실은.)

<인도인 학습자 대상 데이터에서 의지를 찾다.>

Kaggle의 Student Course Completion Prediction Dataset을 뒤적여보았다. (참고한 EDA 페이지: https://www.kaggle.com/code/seki32/course-completion-eda-and-rf-ensemble-classifier)

기계학습용 데이터라는 것이 티 날정도로 칼럼별 비교를 하기엔 너무나 재미가 없다. 위의 EDA페이지만 봐도 알 수 있듯이.

다른 학습플랫폼/학습자 데이터에 나온 motivation칼럼(혹은 motivation을 추정할 수 있는 칼럼)이 없는 것을 보고 우선 가장 눈에 띄는 (지불 방식 중) scholarship을 기준으로 삼아보았다.

장학금 수여시 일단 학습 완료율이 높을 것이라는 예상은 틀렸다.

나이 구간별로 나누어봐도 모든 나이대에서, 직업으로 살펴봐도 모든 상태에서 (학생,재직,실업..), 심지어 과목이 어려웠기 때문일까..하는 마음에 강의레벨을 살펴봐도 고급,중급,초급 강의 모두에서 장학금 수여시에도 완료를 한 사람이 (미완료보다) 적었다.

위에 언급한 부유한 상황이 더해지면 어떨까? 데이터가 인도인 대상, 인도 도시 거주자 기준이니 데이터에 나온 도시들 중 인도의 부유한 도시로 언급되는 5곳에 대해서도 살펴보았다. 단순히 부유한 도시 거주만을 조건으로 삼을 경우, 여전히 미완료자가 많았다. 그런데 장학금 조건을 추가하니, 5개 인도 부자 도시에서 장학금을 수여하는 그룹에서 비로소 (!!!!) 미완료자보다 완료 학습자들이 많았다.

여기에서 부유한 도시에 거주하면서도 장학금을 받고 강의를 완주한 학생들의 특성은 무엇일까?

이미 목이 말라서 물가에 가자마자 물을 마셔야지!하는 상태의 말과 같은, 그냥 동기와 의지가 철철 흘러 넘치는 학습자.
타지역 (위 데이터에는 인도의 빈곤한 도시는 포함되지 않았다.)에서 부유한 도시로 유학하러 왔거나, 재직/구직하며 무엇에든 성과를 보여야 하는 학습자.
결과 수치를 보자마자 2번이 가장 먼저 떠올랐다. 내가 태생적인 이야기꾼이라서인지 모르겠지만, 이렇게 데이터를 좁혀보고, 분석하면서 이야기가 떠오르는 것이 너무나 재미있다. 또한 여러 도시들 중 부유한 도시만 추려서 '부자도시'로 다시 그룹화하여 새로운 데이터를 생성할 수 있겠지. 이렇게 이미 있는 데이터들로 또다른 데이터를 만드는 작업을 틈틈히 해나가고 공유해야겠다.

이미 논문 작업을 하며 수집,전처리,분석한 데이터를 다른 이론과 적용해서 새로 명명하거나 그룹화하는 작업은 많이 했었다. 그런데 그렇게 논문을 작성해봤자 현업에서는 거의 확인을 안하거나 딴 세상 일이다..라고 생각하며 의미있게 참고하지를 않는 듯하다.

데이터를 가지고 이렇게까지 더 만들어내고, 외부의 것과 합쳐서 또다른 의미와 가치를 만들어내는 일이라니. 이거 완전 재미없없
